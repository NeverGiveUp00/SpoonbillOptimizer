# Privacy Statement for Grey Wolf Optimizer (GWO) Implementation

## 1. What data does this code process?
- **This repository contains ONLY the source code for the Grey Wolf Optimizer (GWO) algorithm.**
- **It does NOT collect, store, transmit, or process any personal data, user information, or sensitive information.**
- The code is designed for **mathematical optimization tasks** (e.g., minimizing functions, parameter tuning). All inputs/outputs are numerical values with no inherent link to individuals.

## 2. When might privacy concerns arise?
- If you integrate this GWO code into a larger system that **handles personal data** (e.g., optimizing a healthcare AI model using patient records), **you are responsible for complying with applicable privacy laws** (e.g., GDPR, CCPA).
- **Example scenarios requiring your own privacy policy**:
  - Using GWO to train a model on user-generated data (e.g., social media behavior).
  - Deploying this code in a web service that processes user inputs.

## 3. Our commitment
- We proactively designed this implementation to **avoid any data collection**.
- No telemetry, logging, or external network calls are included in the core code.
- If you find potential privacy issues, [report them](SECURITY.md) under our bug bounty program.

- This statement aligns with:
  - EU AI Act (Article 28, transparency requirements)
